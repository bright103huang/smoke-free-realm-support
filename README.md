# Smoke-Free Realm Support / 无烟境界支持

This is the public support and privacy-information repository for Smoke-Free
Realm. It intentionally contains no extension source code.

## English

- Submit product support questions through [GitHub Issues](https://github.com/bright103huang/smoke-free-realm-support/issues).
- Read the public [privacy policy](https://bright103huang.github.io/smoke-free-realm-support/).
- Do not post passwords, private health information, export files, or other
  sensitive personal data in an issue.
- Smoke-Free Realm is a behavior support tool, not a medical device. For urgent
  medical concerns, contact an appropriate healthcare professional or local
  emergency service.

## 简体中文

- 请通过 [GitHub Issues](https://github.com/bright103huang/smoke-free-realm-support/issues) 提交产品问题或支持请求。
- 可阅读公开的[隐私政策](https://bright103huang.github.io/smoke-free-realm-support/)。
- 请勿在 issue 中发布密码、私人健康信息、导出文件或其他敏感个人数据。
- 无烟境界是行为辅助工具，不是医疗设备。如有紧急医疗问题，请联系合适的医疗专业人员或当地急救服务。

## Repository boundary

This repository publishes support information and the privacy policy only. It
does not grant access to the private application source repository.
